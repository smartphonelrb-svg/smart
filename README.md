# Cajin Batirin 3.7V daga 5V

Shafin Hausa mai bayyana yadda ake amfani da TP4056 mai kariya domin cajar batirin lithium-ion cell guda ɗaya (3.7V nominal) daga USB/adaptor 5V.

> **Tsaro:** Kada a haɗa cell Li-ion kai tsaye zuwa 5V. Yi amfani da TP4056/BMS, ka bi iyakar current ɗin da masana'anta ta bayar, kuma kada ka bar caji ba tare da kulawa ba.

Buɗe `index.html` a browser don ganin circuit da lissafin current.
